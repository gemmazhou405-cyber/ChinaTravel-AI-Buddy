# SEO 优化效果复盘规则

2026-10-22：用户要求持续跟踪每天的优化动作，并根据效果继续调整。适用于所有历史及新增 SEO 修改，最终目标是强相关 Google 自然搜索点击。

## 每次复查的输入与输出

先读取 `optimization-tracker.md`、`effectiveness-review-queue.json` 和对应结构化跟踪文件。逐 URL、逐动作保留：修改内容与假设、代码提交、正式站首次核验日期、Google 报告的收录/抓取/canonical、数据实际起止日期、同页同词展示/排名/CTR/点击、证据文件和下一决定。历史观察只追加，不覆盖；队列是当前工作视图，不能替代历史快照。

每次输出一张简表：**页面／动作 → 正式站状态 → Google 抓取与收录 → 同词排名和相关点击变化 → 结论 → 下一动作**。区分事实、推断和未知。新出现的可见查询写“本次首次观察到”，隐藏查询继续留未知。没有新的 GSC 数据时，结论写待验证，不把原始基线重新称作最新结果。

## 每日检查，按完整窗口评估

- 每日：检查待观察动作、正式版本及新证据；优先处理 HTTP、canonical、noindex、正文/链接或功能回归。Google 索引状态需要 URL Inspection 证据；公开 HTTP200 与 live test 不等于已收录。没有新的抓取报告，只能说“修改后抓取待确认”。
- 首个完整7天窗口：有完整数据后看初步方向。默认从正式版本核验日后一天起；若后来确认抓取更晚，另外保存抓取后的窗口。不要将修改前或不完整日期算作完整效果窗口。
- 完整28天窗口：结合相同 URL、查询、搜索类型、国家/设备条件复盘；记录相邻、不重叠、同长度的参考窗口。参考窗口包含其他改动时注明，不能作干净对照。
- GSC 报告可能延迟；队列中的复查日期只是最早检查点，不能到日即判有效或失败。季节、需求、竞争和查询构成变化也要纳入解释。
- 同页连续多次改动合并观察。技术回归立即修复；一般内容不因一天没有点击或一次排名波动反复改写。

## 怎样决定下一步

| 证据 | 结论与动作 |
| --- | --- |
| 未核验正式版本 | 先核验/修复发布，暂不开始搜索效果判断 |
| 修改后抓取、完整窗口或样本不足 | 待验证；说明缺口，保留当前版本 |
| 同条件下相关点击有改善、查询意图匹配 | 保留；记录绝对变化与归因限制，继续观察稳定性 |
| 同词排名改善但点击不足 | 记录排名信号，检查展示量、意图、SERP和摘要；不当作点击目标达成 |
| 完整窗口内相关展示存在、同词排名持续受限 | 仅对已确认的答案/独有内容/内链缺口提出下一项修改，并建立新的动作记录 |
| 相关查询点击反复下降或意图偏移 | 先核对抓取、窗口、季节和多项改动，再决定局部调整或回退；页面平均排名下降本身不足以回退 |
| 内容错误、技术或功能回归 | 立即修复/回退并验证，不等待7天或28天 |

不设置通用的最低展示量或显著性门槛来伪装结论；小样本写“暂不能判断”。零点击基线报告新增多少点击，不计算百分比增长。构建通过、上线、索引、排名信号和相关点击是不同阶段。

## 点击与选词口径

主指标是强相关 Google 自然搜索点击；同页同词排名、相关展示和CTR是解释指标。将全站点击、相关主题页面点击代理指标、可由查询×落地页确认的相关点击分别记录；无法判定的隐藏查询不擅自算作无关或强相关。

继续按用户的两个维度选词：有真实需求证据的关键词与页面曝光，以及已有关键词的排名机会。GSC展示不是市场月搜索量；页面平均排名不是某一关键词排名。Ahrefs目前返回Insufficient plan，未取得的搜索量/KD保留未知，不贴“高流量低竞争”标签。

2026-10-22用户进一步明确：优先触达想来中国旅游的人。选词先筛旅游意图，再按原有的需求/曝光和同词排名两个维度排序。当前分级与候选见 `tourist-intent-priorities.json`；队列priority表示工作资源顺序，不能当作预期收益分数。

240小时计算器保持第一。旅行预算/费用计算器、明确天数的中国或城市行程、景点交通优先；SIM/eSIM、游客支付、订票、入境、酒店、DiDi/Amap等准备任务紧随，并按实际查询筛选游客使用意图。通用微信账号验证、紧急电话的增长优先级下调，继续维护与跟踪；不因其页面平均排名较好而优先投入。导航/支付也可能来自居民，词含foreigner也不能自动认定为游客；不批量改写为tourist。

优先具体长尾任务，如费用计算、行程天数、景点交通、旅行上网。目标词示例只是候选，不代表已经覆盖、有已知月搜索量或低竞争。品牌新闻、司机招聘、金融/开发者、账号交易及不含中国出行背景的泛验证查询应分开；隐藏查询保持未知。Google官方强调服务明确的目标受众和网站主要用途，当前资源排序是本站经营判断，不是Google排名公式。

最近上线且没有足够新证据的页面保留观察期；只对已确认的答案、独有内容、功能或内链缺口实施小范围修改。技术/事实回归仍立即处理，但不把容易发现技术问题作为增长优先级依据。

## 数据获取与定期任务

现有SEO复查任务改为每日复查，在每日任务内按7天/28天窗口成熟情况复盘。任务读取GitHub中的最新记录，并利用用户提供且可读取的GSC导出/截图。目前没有可直接读取GSC的连接；不使用云浏览器，也不让用户为Ahrefs套餐限制重复登录。

缺数据时每次只请求最必要的1–2个精确URL，给出获取位置：GSC效果→搜索结果→网页精确URL→查询→相同日期比较导出；实际日期与索引/上次抓取截图另记。不重复索取已经收到的全站及计算器基线，不将“已经提出的数据请求”当作数据已取得。

最初请求的Amap/微信精确网页Queries仍是待补证据。按用户最新旅游意图排序，当前最必要的是计算器修改后抓取/canonical，以及旅行预算页的精确Queries与实际日期。每次只请求必要的1–2项，已有基线无需重交；后续依据队列和最新文件调整。

2026-10-30按届时完整数据说明目标进度与缺口。此前的30次相关点击只是以6次全站点击为数量参考的冲刺目标，相关点击基线尚未确认；不能承诺达标或改变窗口制造五倍增长。该日期后继续正常复盘。

## 增长改写前的证据门槛（2026-10-22补充）

每次选增长动作前，先更新关键词机会矩阵（本轮 `keyword-opportunities-2026-10-22.json`）：候选词、已知需求/曝光、页面×查询范围、同词排名、国家/设备条件、竞品答案/功能、已确认缺口、近期改动及数据缺口。搜索量/KD不可取时留未知，公开检索不冒充目标市场Google前十。用户指定重点体现资源顺序，不等于该词已证实高收益或低竞争。

区分三种决定：证据足够的具体增长试验；等待页面查询/抓取/完整窗口；已确认的内容准确性或发布一致性修复。维护修复可立即执行，但不能把它包装成已证实的排名优化机会或点击收益。已有曝光不意味着必须当天改写；近期页在没有新缺口/效果证据时继续观察。每轮报告说明为何选择或暂缓，以及最小必要数据。

跟踪记录含 `serviceNoticeWatch` 时，在复查中检查其来源及有无更新的运营公告；来源不可访问时保留不确定性，不自动续写已核验日期或声称没有变更。证实新的运营安排后，及时更新相应日期化说明并保留旧观察。旅游时效内容的小范围探索试验仍须公开未知搜索量/竞争和查询归属，不能当作已证实低竞争机会。
